Математическая запись формул

N — число участников, P — лимит поражений, t — число туров длинной части, считая от финала. В парном турнире N равно числу пар.

k=⌈log2N⌉ S=2k q=N−2k−1 R=2k−2 a=max(0,q−R) b=min(q,R)

Короткая сетка · приложение 11

F(n,p)= ∑x=0n−1 min{p,w2(x)} M11(N,P) =F(N,P)

w₂(x) — число единиц в двоичной записи x. При n = 0 сумма пуста, а F(n, 0) = 0.

Длинная сетка · приложение 12 А

M12(N,P)= { N−1, P=1 2N−4+ F(a,P−2) +F(b,P−2) +2∑j=1k−3 F(2j,P−2), P≥2

Формула длинной сетки записана для N ≥ 3. При k < 4 сумма по j равна нулю.

Смешанная сетка

B=min(N,2t) Mmix(N,P,t) = F(N,P)− F(B,P)+ M12(B,P)

Допустимо 1 ≤ t ≤ k. Для полного розыгрыша мест можно взять P = k. Для одного участника результат 0, для двух — 1 матч.

Как учитываются свободные места

Калькулятор использует зеркальный посев на ближайшую степень двойки. В первом туре номера соперников дополняют друг друга до числа мест плюс один. Проходы без игры получают первые номера посева.

Когда в ячейке один участник, он проходит в ветку победителя без матча и поражения. Групповой этап, технические результаты и снятия считаются по фактическому протоколу отдельно.

Для конкретного турнира со специальным шаблоном или другой раскладкой свободных мест ориентируйтесь на его протокол. Схемы RTTF · Правило выбывания
